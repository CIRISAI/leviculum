# Baseline for scripts/check-commit-trailers.sh (Codeberg #205).
#
# `baseline` is the commit the guard landed on top of. Everything after it is
# checked; the commit itself and its ancestors are not, because 16 of them
# carry a machine-authorship trailer from before the rule had anything behind
# it, and rewriting published history to remove them is the larger harm.
#
# `legacy` is how many of those there are. The guard recomputes it on every
# run and fails if it disagrees. That is the point: a baseline nobody counts
# behind is an off switch, and bumping it forward to silence a fresh failure
# would either carry a new violation below the line or drop an old one above
# it. Either way this number moves and a reviewer sees it. The concept page
# makes the same objection to expiry dates -- a bound a one-line diff can
# bump is not a bound.
#
