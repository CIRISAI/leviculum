# Pinned census of the environment knobs the shipped code reads (#347).
#
# An environment variable that changes what a daemon does is a knob nobody
# configured: it is not in the config file, no status tool reports it, and two
# runs taken under different values look identical afterwards unless the code
# said so out loud. #347 added exactly such a knob and it is meant to be
# DELETED when the experiment it serves answers, so the list has to be able to
# say "temporary, and this is what removes it" -- and has to go red when a
# knob is added without saying anything at all, and again when a knob is gone
# but its line is not.
#
# scripts/check-env-knobs.py rebuilds the set from the sources and fails
# `just fast` on any difference in either direction. Format: one
#
#     <KNOB> <temporary|permanent> <reason>
#
# per line. A `temporary` line must name its issue (#NNN) and what removes it;
# a `permanent` line says why the knob outlives any one experiment. Counted:
# every `LEVICULUM_*` literal in a non-test, non-build Rust source that is not
# inside an `env!`. See the script's docstring for the rest of the rule.

LEVICULUM_JITTER_ARM temporary #347 the four-arm A/B selector for the RNode host interface's acquisition jitter (leviculum-std/src/interfaces/rnode.rs::JitterArm). Arm 4 joined on 2026-09-25 as arm 3's rule over a shorter count span, a separate arm rather than a knob on arm 3 so that a run document names one policy. Removed with the arms that lose the co-release series: the winner becomes the unconditional policy, the enum, the variable and arm_owed_jitter_ms go, and this line goes with them.
LEVICULUM_SUBSLOT_ARM temporary #438 the two-arm A/B selector for the sub-slot offset on the RNode host interface's acquisition draw (leviculum-std/src/interfaces/rnode.rs::SubslotArm, leviculum-nrf/channel-access ChannelAccess::set_subslot_offset), default off. Removed when the rig A/B answers: the offset becomes unconditional or is deleted, SubslotArm and the variable go, and this line goes with them.

LEVICULUM_EVENT_LOG permanent operator diagnostic: the path the structured event log is written to (leviculum-std/src/event_log.rs, docs/src/structured-event-logs.md). Selects a sink, never a behaviour on the air.
LEVICULUM_EVENT_LOG_SYNC permanent operator diagnostic: opt back in to the pre-#418 blocking write on the emitting thread, for a crash where the buffered writer would lose the last lines. Sink discipline, not protocol.
LEVICULUM_EVENT_NODE permanent operator diagnostic: the node name stamped into each event-log line, so a multi-node run merges into one timeline.
LEVICULUM_RESOURCE_WINDOW_POLICY permanent #85 selects the resource receive-window algorithm. Deliberately an environment variable and not a config key, because the config format is shared with Python rnsd and must not grow leviculum-only keys (leviculum-std/src/resource_policy.rs). No removal condition has been stated for it, so it is not claimed here to be temporary.
LEVICULUM_NO_AUTO permanent #471 the lab guard of the automatic layer, beside the host marker /etc/leviculum/no-auto (leviculum-std/src/auto_layer.rs, docs/src/concepts/zero-config.md): 1 turns every [auto] medium off, 0 lifts the marker so a cell can measure the layer on a marked host. Permanent because the automatic layer is shipped behaviour and the rig hosts need a switch that no config file can carry. Never silent: lnsd names it in its AUTO_LAYER line as reason=env when it turned off a medium the configuration asked for.
LEVICULUM_AUTO_SERVERS permanent #471 step 3 pins the automatic layer's server list (leviculum-std/src/auto_servers.rs, docs/src/concepts/zero-config.md): host:port entries dialled in their order, set but empty a list of none. Permanent because a periculum cell has no other way to point a configless lnsd at its own nodes instead of the public list, and an operator pins with it too. Never silent: every slot's entry is an AUTO_SERVER line with reason=pinned, and an empty list logs chosen=none reason=empty.
LEVICULUM_AUTO_SERIAL_DIR permanent #471 step 5 names the directory the automatic layer's serial medium reads boards from, instead of /dev/serial/by-id (leviculum-std/src/auto_serial.rs, docs/src/concepts/zero-config.md). Permanent because a periculum cell has no other way to hand a configless lnsd its pty devices instead of the host's real boards, and the zero-config fixture points every subject at an empty directory by default so a netns cell on the rig host never reaches them. Never silent: every entry the medium reads is an AUTO_SERIAL line naming its by-id name.
LEVICULUM_AUTO_BLUETOOTH_ADAPTER permanent #471 step 6 names the one Bluetooth adapter the automatic layer's Bluetooth medium may take, instead of BlueZ's default adapter (leviculum-std/src/auto_bluetooth.rs, docs/src/concepts/zero-config.md); a name BlueZ does not list is no adapter. Permanent because a periculum cell has no other way to hand a configless lnsd its own btvirt controller instead of the host's real adapter, and the zero-config fixture names an adapter that does not exist by default so a netns cell on the rig host never joins the room. Never silent: the medium's verdict is an AUTO_BLUETOOTH line naming the adapter it took, and the section it adds names it as its device.
LEVICULUM_LNSD permanent #471 step 4 names the lnsd a client tool starts when no shared instance answers (leviculum-std/src/instance.rs, lnsd_program), over the one beside the tool and the one on PATH. Permanent because an installed tool, a cargo build and a test harness keep lnsd in different places, and a tool with no config file of its own has no other place to be told. Selects a program, never a behaviour on the air; the started daemon is named in the INSTANCE line by its pid.
LEVICULUM_APPEND_BENCH_DIR permanent names the disk an #[ignore]d append-cost measurement runs on (leviculum-std/src/file_propagation_store.rs, in its #[cfg(test)] module). Reaches no daemon; it is in this census only because a cfg(test) module inside a src/ file is not something the scanner can exclude.
LEVICULUM_OPEN_BENCH_DIR permanent names the disk an #[ignore]d store-open measurement runs on and keeps its 320 000-file fixture (leviculum-std/src/file_propagation_store.rs, in its #[cfg(test)] module, order 1376). Reaches no daemon; in this census only because a cfg(test) module inside a src/ file is not something the scanner can exclude.
LEVICULUM_OPEN_BENCH_MESSAGES permanent the fixture size of that same #[ignore]d store-open measurement, 320 000 by default (order 1376). Reaches no daemon, as above.
LEVICULUM_HEAP_SAMPLE permanent operator diagnostic, read only by an lnsd built with the default-off heap-accounting feature (leviculum-cli/src/lnsd.rs::configure_heap_sampler, leviculum-std/src/heap_accounting.rs): every n-th allocation records its call site for the SIGUSR1 census (508, Codeberg #437). Off unless set, logged at startup when set, and it changes what the census prints, never what goes on the air.
LEVICULUM_I2P_SAM permanent the SAM bridge address the two #[ignore]d live I2P tests dial (leviculum-std/src/interfaces/i2p/i2pd_live.rs, a #[cfg(test)] module); `just i2p-live` points it at a router of the private I2P network it starts (scripts/i2p-privnet.sh). Reaches no daemon; in this census only because a cfg(test) module inside a src/ file is not something the scanner can exclude.
LEVICULUM_I2P_SAM_PEER permanent the second SAM bridge of the same #[ignore]d live loopback test (leviculum-std/src/interfaces/i2p/i2pd_live.rs, cfg(test)): its connecting side dials it, so on the private I2P network the stream crosses from one router to another (1576); unset, the test keeps both ends on LEVICULUM_I2P_SAM. Reaches no daemon; here for the same scanner reason as the line above.
