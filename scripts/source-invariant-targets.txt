# Verdicts for every `tests/` target in the workspace: does `just fast` run it?
#
# Codeberg #220 put a compile check of every target on the push path, and that
# is where the push path stopped: `check-all-targets` proves each `tests/`
# target BUILDS and nothing before `just standard` proves any of them PASSES.
# On 2026-09-22 that cost 18 commits a landing gate and two red cycles, and the
# break was attributed to a commit two batches old because no gate in between
# had run the file.
#
# THE CLASS CRITERION
# -------------------
# A target is admissible to the `run` list iff all four hold:
#
#   1. The thing under test is a FILE IN THIS TREE -- a document, a config, a
#      catalogue, a vendored artifact, the text of a source file. The target
#      reads it and asserts a property of what it read. This is what makes the
#      class worth the push path at all: such a target goes red from an edit
#      that changes no code any other Tier-0 gate compiles, which is precisely
#      the hole `--lib` gates cannot see.
#   2. It starts no process.
#   3. It opens no socket and touches no device.
#   4. It finishes in milliseconds.
#
# A target whose subject is the CODE -- a golden render, a vector corpus, an
# in-process protocol suite -- fails (1) even when it is fast and pure. That
# boundary is deliberate: without it this list grows into `cargo test
# --workspace`, which is a bill nobody has agreed to pay on every push.
#
# Where a target is close to the line it goes in `skip` with the reason. The
# skip list is not the failure half, it is the honest half.
#
# WHAT ENFORCES THIS FILE
# -----------------------
# `scripts/check-source-invariant-census.py` (recipe: check-source-invariant-
# census, in `just fast`) enumerates every `test`-kind target cargo knows about
# and fails if any one of them has no verdict here, if a verdict names a target
# that no longer exists, if a target is listed twice, or if an entry states no
# reason. Adding a `tests/` file therefore fails the gate until somebody
# decides which half it is in -- the shape `scripts/ignored-counts.txt` already
# uses, and for the same reason: nobody has to remember, because forgetting is
# what goes red.
#
# WHAT ENFORCES NOTHING
# ---------------------
# Nothing here checks that an admitted target actually MEETS the criterion. A
# target that spawns a daemon, admitted to the `run` list, is run by `just
# fast` and the gate stays green; it just costs what it costs. The only thing
# standing between that and the push path is the one-line reason below, in a
# diff, read by a person. Said plainly rather than papered over with a source
# grep that a helper module would defeat.
#
# FORMAT
#   <run|skip>  <package>  <target>  # <reason, one line>
# Blank lines and whole-line `#` comments are ignored.
