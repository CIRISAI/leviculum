Leviculum is a Rust implementation of the [Reticulum](https://reticulum.network/) network stack: encrypted mesh networking over LoRa, TCP, UDP, serial or Bluetooth, with no servers and no accounts.

## What runs it

- `lnsd`, the daemon, on Linux and macOS
- The LNode firmware on nRF52 [boards](/boards): Heltec T114, RAK4631, RAK WisMesh Pocket V2
- Tools: `lncp`, `lnstatus`, `lnflash`, `lnomad`, `lnpnd`

## Two promises

- Wire compatible with Python Reticulum
- The same code from daemon to microcontroller

## Status

Active development, nightly builds, no release yet.
